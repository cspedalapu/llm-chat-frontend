A Research tab that does one job well

Ask a question, choose the models and sources, approve a plan, watch the research happen, and get a cited report. The same tab connects research tools (web, academic, Google, Microsoft, Excel, any MCP tool) and tracks every call they make.

Research summary

What ChatGPT, Claude, Gemini, Grok, DeepSeek and Perplexity do

From official docs where reachable. Items in italics could only be confirmed from secondary sources.

Plan before you spend

ChatGPT and Gemini show an editable research plan before a run starts. That's the step the others lack.

Runs are background jobs

2–30 minutes, keep going if you leave, can be stopped. ChatGPT also lets you steer mid-run.

Tools arrive over MCP

ChatGPT and Claude accept any remote MCP server. Research uses tools read-only, with per-tool permissions.

Our own loop wins

OpenAI retired its deep-research models on 23 Jul 2026. A normal model plus our tools works for every model we support, DeepSeek included.

The page

The Research tab

A new sidebar item that replaces the old "Deep Research" placeholder. It shows only when the backend supports research, and each user can hide it in Customize.

Left

Research history. A running job shows a live dot and keeps going if you leave.

Centre

Ask → plan → live run → report. Pick depth, a research model and, optionally, a separate writer model.

Right

Every connected tool with its status and call count. Manage tools opens the directory.

A research run

How a run works

Amber steps are where you're in control; the others run on their own.

Ask

Question, depth, models, sources, "plan first".

You

Clarify

0–3 questions, only if the question is ambiguous.

Optional

Approve plan

Edit the sub-questions and sources. See a cost and time estimate. Start or cancel.

You

Live run

Timeline of searches, pages read and tool calls. Stop or Add instruction any time.

Background

Report

Contents, [n] citations, sources panel, export MD / DOCX / PDF, continue in chat.

Result
Behind the scenes
Plan→Sub-researchers in parallel→search · fetch · read tools→Notes tied to sources→Writer model drafts report→Every [n] checked against fetched text

Saved as it goes, so a reload never loses it. Web and connector content is treated as data, never as instructions. Only URLs from search results or supplied by you are fetched.

Decisions before we start

Each has a recommendation. Red means only you can answer it.

Web search provider

DR-1

Recommended: pluggable; one paid API (Tavily, Brave or Perplexity Search) plus free self-hosted SearXNG.

Needs your API key.

Base or fork?

DR-2

Recommended: in the base as an optional feature; any fork can switch it off.

What "Google Cloud" means

DR-3

Google Drive / Docs / Sheets, or GCP data such as BigQuery and Cloud Storage?

How Google and Microsoft connect

DR-4

Recommended: direct read-only APIs first; MCP for everything else.

Excel depth

DR-5

Recommended: read and summarise first; running code on data later, sandboxed.

Budgets and first scope

DR-6 · DR-7

Recommended: Quick / Standard / Deep as above; M1 = web, academic, library, Excel.
